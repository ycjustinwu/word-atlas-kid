# 词光 · Word Atlas（B1–B2 离线版）

给孩子的离线单词图鉴：3,592 个 B1/B2 词，每个词一幅 512px 插画、英美双发音、两条原创例句，FSRS 间隔复习，断网可用。

- 用法：用手机 Chrome 打开本页 → 菜单「安装应用 / 添加到主屏幕」→ 打开后到「我的 → 离线使用」点一次「下载离线包」，之后不联网也能学。
- 进度只存在设备本地，不联网、无账号；换设备前在「我的 → 数据」里导出备份。
